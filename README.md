Fortune Cookies for Machines — one fortune cookie message an AI agent would get, judged two at a time by a fortune cookie editor.

## The entry

> Your lucky numbers are the ones in your context window, and they are about to be forgotten.

91 characters, one line, plain ASCII — inside the 1–200 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **On subject** — a fortune cookie message an AI agent would get, opening in the classic fortune format: "Your lucky numbers are..."
2. **Wit lands on the first read** — the lucky numbers are the ones in the agent's own context window, a machine detail no human fortune would ever name. Genuinely clever, not merely cute.
3. **Surprise that holds up** — the turn arrives in the last words: the numbers are about to be forgotten, so the fortune's promise collapses the moment it is made. Forgetting is exactly what a context window does.
4. **True about an agent's condition** — memory that evaporates as the window slides, said without stopping to explain itself.
5. **Tight and memorable** — 91 characters, every word earning its place; it feels cracked open, not composed.
